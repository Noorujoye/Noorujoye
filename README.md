### 🔥 Featured Projects

#### 🏛️ [Indore Municipal Corporation (IMC) — Vendor Management System](https://github.com/Noorujoye/Indore-Muncipal-Corporation-website)
> **Full-Stack Enterprise Workflow System | Java 21 • Spring Boot • PostgreSQL • React 19 • Vite • Spring Security**

- **Multi-Tier Finite State Machine**: Architected a sequential invoice approval chain across 4 distinct roles (`Vendor` $\rightarrow$ `Creator` $\rightarrow$ `Verifier` $\rightarrow$ `Approver` $\rightarrow$ `Paid`) with strict guardrails preventing unauthorized state skipping.
- **Robust Security Architecture**: Built dual-token stateless JWT authentication (15m access / 7d refresh token) with Axios race-condition request interceptors and BCrypt password hashing.
- **Data Integrity & Compliance**: Designed relational schema across 8 entities in PostgreSQL with composite unique constraints, automated GST split calculations (9% CGST + 9% SGST), and immutable audit logs.
- **Full-Stack Polish**: Delivered 100% bilingual (English/Hindi) localization, mobile-first responsive cards for viewports $\ge 360\text{px}$, transactional Brevo SMTP notifications, and validated 42 QA test scenarios with a 100% pass rate.
